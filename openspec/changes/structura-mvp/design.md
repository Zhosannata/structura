# Design: Structura MVP

## Context

Structura — AI-сервис для PM/BA. Принимает сырое требование, возвращает полный пакет проектной документации для команды: ТЗ, User Story, AC, задачи по ролям, тест-кейсы.

## Goals / Non-Goals

**Goals:**
- Генерация ТЗ, User Story, AC, задач по ролям, тест-кейсов
- Валидация вывода через Pydantic
- Сохранение генераций с версионированием

**Non-Goals:**
- Голосовой ввод
- Экспорт в Jira
- Командная работа

## Decisions

- **LLM:** GigaChat (доступен в РФ, русскоязычный)
- **Валидация:** Pydantic-схема + golden dataset
- **Промпт:** версионируется в Git (`prompts/v1/`)
- **Декомпозиция:** задачи группируются по полю `role`

## Risks / Trade-offs

- LLM может пропустить роль → golden dataset + тесты
- Промпт может устареть → версионирование
