# Delta for Structura UI

## ADDED Requirements

### Requirement: Форма ввода требования

The system SHALL предоставлять веб-форму для ввода сырого бизнес-требования на главной странице.

#### Scenario: Открытие главной страницы
- **GIVEN** пользователь открыл `GET /`
- **WHEN** страница загружается
- **THEN** отображается форма с текстовым полем `requirement` и кнопкой «Сгенерировать»

#### Scenario: Пустой ввод
- **GIVEN** пользователь отправил форму с пустым полем
- **WHEN** `POST /generate` получает пустую строку
- **THEN** возвращается страница с сообщением об ошибке, форма остаётся доступной

### Requirement: Обработка запроса на генерацию

The system SHALL принимать требование через `POST /generate` и возвращать страницу результата.

#### Scenario: Успешная генерация
- **GIVEN** пользователь отправил непустое требование
- **WHEN** Qwen через Polza.ai вернул валидный `StructuraOutput`
- **THEN** рендерится страница результата с ТЗ, User Story, AC, задачами по ролям, тест-кейсами и рисками

#### Scenario: Ошибка провайдера LLM
- **GIVEN** Polza.ai недоступен или вернул ошибку
- **WHEN** сервис не смог получить валидный ответ
- **THEN** возвращается страница с понятным сообщением об ошибке и предложением повторить

#### Scenario: Невалидный ответ модели
- **GIVEN** Qwen вернул текст, не соответствующий схеме `StructuraOutput`
- **WHEN** Pydantic не смог провалидировать
- **THEN** возвращается страница с ошибкой валидации, детали логируются

### Requirement: Отображение результата

The system SHALL отображать все сгенерированные артефакты на странице результата.

#### Scenario: Полный пакет документов
- **GIVEN** `StructuraOutput` содержит все поля
- **WHEN** рендерится `result.html`
- **THEN** отображаются: ТЗ (цель, scope, ограничения), User Stories (role/action/value), AC (GIVEN/WHEN/THEN с типом main/edge), задачи сгруппированные по ролям, тест-кейсы со ссылкой на `ac_id`, риски

### Requirement: Дизайн-палитра

The system SHALL использовать согласованную палитру во всех шаблонах.

#### Scenario: Единообразие цветов
- **GIVEN** пользователь открыл любую страницу
- **WHEN** страница отрендерена
- **THEN** фон `#F8FAFC`, акцент `#2563EB`, текст `#1E293B`, границы `#E2E8F0`

### Requirement: Конфигурация провайдера

The system SHALL читать параметры Polza.ai из переменных окружения.

#### Scenario: Загрузка конфига
- **GIVEN** в `.env` заданы `POLZA_API_KEY`, `POLZA_BASE_URL`, `LLM_MODEL`
- **WHEN** приложение стартует
- **THEN** `Settings` загружает их через `pydantic-settings`

#### Scenario: Отсутствует ключ
- **GIVEN** `POLZA_API_KEY` не задан
- **WHEN** приложение стартует
- **THEN** `Settings` выбрасывает ошибку валидации с понятным сообщением
